# 复用层照抄存量字段定义，不做合规纠正

三级决策的最高级"复用"（录入字段中文名与既有字段 COMMENT 中文名精确匹配）命中时，直接照抄本系统存量字段的英文名与类型——**即使该定义违反当前审核要求**（如金额字段用 FLOAT、命名含大写）。理由：复用层的价值是系统内一致性，新表与同系统在用字段保持一致，比符合新规则更重要；这与"存量公共集兼容采用"（复用选词结构、不自行改写）同一取向。曾考虑的替代方案是命中时纠正为合规定义，被否决——纠正会造成同系统内"同义不同名/同名字段两种类型"，正是审核要求 §4"数据项唯一性"要消灭的情况。

注意：照抄仅限字段名与类型；NOT NULL、默认值、COMMENT 等通用 DDL 约束仍按规则引擎正常补齐。未来维护者若发现工具对金额字段产出 FLOAT，这是刻意行为，不是 bug；翻转此决策会改变所有复用命中的生成语义。
