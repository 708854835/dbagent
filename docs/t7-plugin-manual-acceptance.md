# T7 IDEA 插件向导 — 手动验收清单

> UI 无自动化缝，以下条目在安装插件后的 IDEA 2024.1+ Community 中逐项手动执行。
> 前置：引擎已启动（`serve --master-key`），`config/engine.yaml` 含 DEMO 数据源与有效 Token。

## 1. 安装与入口（验收 5.19）

- [ ] `plugin/build/distributions/` 下 zip 通过 Settings → Plugins → ⚙ → Install Plugin from Disk 安装成功，重启无报错
- [ ] Tools 菜单出现「新建数据库表（向导）」与「刷新 Schema 缓存（DbAgent）」
- [ ] 任意编辑器右键菜单出现「新建数据库表（向导）」

## 2. 首次配置（验收 5.1 / 本地保存）

- [ ] 打开向导 → 连接设置页：填引擎地址、NotesID（zhangsan）、Token（demo-token-zhangsan）
- [ ] 生成一次后关闭 IDE 重开：引擎地址与 NotesID 已回填；Token 存 PasswordSafe（`config/options/dbagent.xml` 无 Token 明文）

## 3. 向导校验分级（验收 5.1）

- [ ] 表中文名留空 → OK 被阻断并提示「阻断级」
- [ ] 某行字段中文名留空 → 阻断并定位行号
- [ ] 录 28 个字段（含自动补齐超 30）→ 阻断提示拆表
- [ ] 表名含「和」/超 15 汉字 → 仅底部橙色警告，可继续

## 4. 生成与预览（验收 5.1 / 5.16）

- [ ] 表单「客户台账 + 客户编号(必填,32) + 合同编号(32)」→ 预览弹出，表名 t_kh
- [ ] 字段表格显示来源徽章（复用·本系统/贯标·字典/推导·待登记/LLM·候选/需人工复核/已确认复用）
- [ ] 「需人工复核」行整行高亮（浅红底）
- [ ] 缓存命中场景生成响应 ≤ 2 秒

## 5. 修正与重新生成（locked 增量语义）

- [ ] 修改某字段英文名 → 「重新生成」→ 该字段照抄不重算，其余字段决策不变
- [ ] 修改物理表名 → 「重新生成」→ DDL 使用新表名
- [ ] 表名改为非法值（大写/连字符）→ 400 友好提示「锁定表名…非法」

## 6. 索引与 SQL 输出（验收 5.1）

- [ ] 索引复选框默认全选；主键项禁用且标注「已含于 DDL」
- [ ] 取消某索引勾选 → 复制 SQL 中无对应 ADD INDEX 行
- [ ] 「复制 SQL」→ 剪贴板内容为 DDL + 选中索引 ALTER TABLE ADD INDEX
- [ ] 打开 .sql 文件时光标处「插入编辑器」成功；无活动编辑器时自动新建 .sql 临时文件

## 7. 登记落库

- [ ] 「完成并登记」→ 通知「已登记 N 个字段定义」
- [ ] 同表单再次生成 → 已登记字段徽章变「复用·本系统」（已确认候选复用）

## 8. 刷新 Schema 缓存（验收 5.10 零 JDBC）

- [ ] Tools → 刷新 Schema 缓存：全程未填任何 JDBC 参数，通知反馈「拉取 N 张表 / M 个字段」
- [ ] 引擎未配置该系统数据源时 → 错误提示「未提供 jdbcUrl 且引擎未配置存储数据源」

## 9. 异常路径（验收 5.11）

- [ ] 停掉引擎后生成 → 通知「引擎不可达…请确认引擎服务已启动」，IDE 无异常弹窗
- [ ] Token 填错 → 通知「Token 无效或已过期，请联系管理员重新签发」
- [ ] 表单 NotesID 与 Token 绑定不一致 → 同上 401 提示

## 10. 全流程耗时（验收 5.15）

- [ ] 熟练用户从打开向导到拿到最终 SQL ≤ 3 分钟
